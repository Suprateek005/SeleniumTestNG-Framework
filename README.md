# Selenium TestNG Hybrid Automation Framework > Automation testing framework for [DemoWebShop](https://demowebshop.tricentis.com/) > built with Selenium WebDriver, TestNG, and ExtentReports. ## Tech Stack | Tool | Purpose | |---|---| | Selenium WebDriver 4.x | Browser automation | | TestNG 7.x | Test execution & reporting | | Apache POI | Data-driven testing (Excel) | | ExtentReports 5.x | HTML test reports | | Maven | Build & dependency management | ## Project Structure ``` src/main/java/generic_Utilies/ → BaseClass, Utilities src/main/java/Object_Repository/ → Page Object classes src/test/java/TestScripts/ → Test cases src/main/resources/ → config.properties, reports testng.xml → Test suite configuration ``` ## Features - Cross-browser testing: Chrome, Edge, Firefox - Parallel test execution via TestNG XML - Page Object Model (POM) design pattern - Hybrid framework (Data + Keyword driven) - Auto-generated HTML reports using ExtentReports ## How to Run 1. Clone the repo ```bash git clone https://github.com/Suprateek005/SeleniumTestNG-Framework.git ``` 2. Update `src/main/resources/config.properties` with your credentials 3. Run via Maven: ```bash mvn test ``` 4. Or right-click `testng.xml` → Run As → TestNG Suite in Eclipse ## Test Modules - Cart Test - Address Test - Purchase Test ## Author **Suprateek S** · [LinkedIn](https://www.linkedin.com/in/suprateekqa/) · [GitHub](https://github.com/Suprateek005)
